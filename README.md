# 🐍 Python — 100 Exercícios | Curso em Vídeo

Resolução dos **100 exercícios de lógica de programação em Python**, propostos pelo professor **Gustavo Guanabara**, do [Curso em Vídeo](https://www.cursoemvideo.com/curso/python-3-mundo-1/).

O projeto foi desenvolvido com o objetivo de **praticar lógica de programação, fortalecer os fundamentos do Python e desenvolver raciocínio para resolução de problemas**, mantendo cada exercício organizado e documentado.

---

## 📚 Sobre o projeto

Este repositório reúne minhas resoluções dos exercícios propostos ao longo do curso.

Cada exercício possui seu próprio arquivo `.py`, desenvolvido utilizando **Python 3**, permitindo acompanhar minha evolução ao longo dos estudos.

## 🚀 Como executar

### 1. Clone o repositório

No terminal, execute:

```bash
git clone https://github.com/Gabriel-Orlandi-Portes/Lista-Logica-CursoEmVideo-Python.git
```

Entre na pasta do projeto:

```bash
cd Lista-Logica-CursoEmVideo-Python
```

### 2. Verifique a instalação do Python

No terminal:

```bash
python --version
```

Ou, dependendo do sistema:

```bash
python3 --version
```

É recomendado utilizar **Python 3**.

### 3. Execute um exercício

Entre na pasta dos exercícios:

```bash
cd exercicios
```

Depois, escolha o exercício que deseja executar:

```bash
python ex001.py
```

Para executar outro exercício:

```bash
python ex002.py
```

E assim por diante.
